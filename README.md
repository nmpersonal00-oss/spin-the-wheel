# Spin the Wheel ♡

A private, ad-free kawaii wheel app using original AI-generated illustrations. No accounts or trackers.

## Features

- Add, remove, shuffle, or reset choices (up to 60).
- Smooth, unbiased spin with a clearly displayed winner.
- Separate desktop artwork and phone-friendly layout.
- Winner celebration with illustrated flowers, hearts, and cheering/applause.
- Separate illustrated app icon.
- Choices and sound preference persist on this device using local storage.
- `index.html` is in the root for GitHub Pages.

## Publish to GitHub Pages

In the repository Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/(root)**.
Your URL will be `https://nmpersonal00-oss.github.io/spin-the-wheel/`.

## Audio credit

The winner sound uses the public-domain recording [Clapping hurray.ogg](https://commons.wikimedia.org/wiki/File:Clapping_hurray.ogg) by Zack and friends, from PDSounds (via Wikimedia Commons). A synthesized audio fallback is included for browsers that cannot stream the file. The remote recording needs an internet connection; the fallback can work offline.
